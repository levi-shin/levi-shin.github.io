# 1125labs.com

디아블로 2(Diablo 2) 1.3 버전 및 래더 오픈을 대비한 실전 앵벌 데이터 공유 및 공략 허브입니다.

## 🛠 주요 특징
- **실전 검증 데이터**: 실제 플레이를 통해 검증된 최적화 세팅 정보.
- **효율 중심**: 군더더기 없는 옵션 데이터와 수치 위주의 직관적인 공략.
- **지속적인 업데이트**: 래더 환경에 맞춘 최신 아이템 DB 및 공략 업데이트.
